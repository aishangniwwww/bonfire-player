优化 · 极限加速
模式常规
常规：优化一次就收工。竞技：优化后本程序保持高优先级，网络参数长期保持。自定义：什么都不自动做，你自己逐项点。
后台治理关闭
正常：把符合条件的后台进程降到「低于正常」；激进：降到「低」。系统关键进程、资源管理器、本播放器不动；关闭会按原值恢复。
极限清理扫描中…
性能优先级普通
核心分配全核
性能核按注册表里每核标称主频认（≥同代最高频的 92%）；禁超线程保留偶数核，避免两个逻辑核抢一个物理核。
网络未测
清 DNS 缓存、开 TCP 自动调优与 ECN；只改网络栈参数，不动端口与代理。
计时器精度系统默认
timeBeginPeriod(1) 把系统计时粒度压到 1ms，节拍更准；退出程序自动松开。
内存清理—
对非关键进程 EmptyWorkingSet，再用 NtSetSystemInformation 清 standby list（后者要管理员权限，失败会如实标注）。
系统开关—
游戏模式写 HKCU\GameBar；电源走 powercfg /setactive；桌面合成把 dwm.exe 提到「高」，卡顿时立刻见效，可随时恢复。
核心隔离关闭
前台留出干净核，后台进程亲和限制到尾部核心；关闭按原掩码逐个恢复。系统关键进程不动。
指定程序优先级（IFEO）
按程序名写 HKLM\…\Image File Execution Options\<exe>\PerfOptions，下次启动即生效；要管理员权限，可一键清除。
设备中断 · MSI / IRQ / 亲和读取中…
直接写设备注册表：MSISupported（MSI 模式）、DevicePriority（IRQ 优先级）、 DevicePolicy + AssignmentSetOverride（中断亲和）。改完全部可一键还原，重启设备后生效；写 HKLM 需要管理员。
反作弊兼容关闭
开启后把 Vanguard / EAC / BattlEye / ACE / nProtect 等进程加进保护名单，后台治理与核心隔离都不再碰它们，避免进游戏被踢。
游戏插件清理未扫描
只在检测到本机装有英雄联盟时出现目标：清 Game\Logs、Config\Logs、TencentDL 等缓存目录，不动游戏本体与配置。
帧率限制（RTSS）检测中…
帧率限制靠写 RTSS 的 Global profile 实现。没装 RTSS 时点「安装 RTSS」会直接打开 RTSS 官网下载页，装好后回到这里刷新，就会自动接管。
